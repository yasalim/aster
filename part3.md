# Часть 3. Сервис выдачи ценовой вилки

`POST /price` принимает признаки, доступные в момент приёма автомобиля, и
возвращает `price_from`, `price_to`, валюту и дату последней обучающей записи.
Модель загружается из `artifacts/price_band_model.joblib` один раз и кешируется
в процессе приложения.

## Запуск

```bash
python src/train_price_model.py
uvicorn api:app --app-dir src --host 0.0.0.0 --port 8000
```

Swagger UI: `http://localhost:8000/docs`.

Пример минимального запроса:

```json
{"mark":"Toyota","model":"Camry","car_year":2020,"mileage":85000}
```

## Защита от поломок

- пустой запрос и некорректные диапазоны дают HTTP 422;
- неизвестные поля запрещены, поэтому постфактум-цены не могут незаметно попасть
  в модель;
- отдельный тест проверяет, что сохранённый feature list не пересекается с
  `FORBIDDEN_FEATURES`;
- неизвестные категории кодируются глобальным средним train, без обращения к
  будущему таргету;
- квантильное пересечение устраняется сортировкой границ.
